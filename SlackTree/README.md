#  # Stack Tower

A hyper-casual tower-stacking game built for iOS using SwiftUI and SpriteKit.

## Overview

Stack Tower challenges players to stack moving blocks accurately
and build the tallest tower possible.

## Tech Stack

- Swift 5.9+
- SwiftUI
- SpriteKit
- UserDefaults
- UIKit haptics
- iOS 16+

## Features

- [ ] Main menu
- [ ] SpriteKit gameplay
- [ ] Score and best-score tracking
- [ ] Pause and resume
- [ ] Game-over screen
- [ ] Haptic feedback
- [ ] System sound effects
- [ ] Restart and replay

## Architecture

- `App/`: Application entry point
- `Views/`: SwiftUI screens and SpriteKit hosting
- `Game/`: Game scene, state, and view model
- `Core/`: Theme, persistence, haptics, and sound

## Requirements

- macOS with Xcode
- iOS 16+ deployment target
- iPhone simulator or physical iPhone

## Getting Started

1. Clone the repository.
2. Open `StackTower.xcodeproj` in Xcode.
3. Select an iPhone simulator.
4. Build and run the app.
